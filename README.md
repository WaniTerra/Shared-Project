Welcome to my repository! Here you can find various software projects I have developed. While these originated as school assignments, I have independently expanded them with additional features and complex mechanics.

I place a strong emphasis on understanding core system mechanics, which is why I frequently implement my own data structures from scratch rather than relying entirely on standard built-in libraries.

Java
Drop Number: A dynamic puzzle game inspired by 2048. The core game mechanics and grid management are built entirely using custom Linked Lists. Although the original requirement was just a scripted scenario, I scaled the architecture to support a fully playable, independent game loop.

Movie Recommendation System: A recommendation engine utilizing a Heap-based filtering algorithm. To demonstrate a deep understanding of data organization, I built the entire Max Heap and Linked List systems entirely from scratch, intentionally avoiding pre-built Java array systems or collection frameworks.

News Portal: A content management application where users can dynamically write, publish, and read news articles.

C
Pokemon Text Game: A text-based tactical battle simulator focused on terminal output and logic flow.

Python
Product-Sale Management: An e-commerce simulation tool designed to manage inventory, sales operations, and transactions, simulating a backend structure similar to Amazon.
